# Publication through platform adapters

Every publication is routed through the platform adapter resolved for the delivery's connection from a single registry, so a platform with no adapter is unsupported identically in the composer, the scheduler, and the publisher. The publisher keeps everything platform-neutral — capability validation, public media staging, durable cleanup, and the retry lifecycle — and adapters keep only what needs platform knowledge: the outward call, whether a media type can be uploaded directly instead of staged publicly, and how to read that platform's failure as authentication, canceled, or uncertain. Publishing therefore reports platform-neutral errors, and the shell unwraps an adapter's own error only where Instagram-specific detail such as a revoked credential still matters.
